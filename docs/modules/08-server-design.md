## 8.2 MQTT Broker

### 8.2.1 推荐方案

- **EMQX** - 功能丰富，支持高并发
- **Mosquitto** - 轻量级，适合小型部署

### 8.2.2 配置要求

| 配置项 | 值 |
|-------|-----|
| 端口 | 1883 (TCP), 8883 (TLS) |
| 认证 | 用户名/密码 或 JWT Token |
| QoS | 控制指令 QoS 1 |
| 持久会话 | 启用 |

### 8.2.3 主题权限

- 设备只能发布/订阅自己的主题
- 工程师可以访问所有配对设备的主题

## 8.3 SOCKS5 中转服务

### 8.3.1 配置要求

| 配置项 | 值 |
|-------|-----|
| 端口 | 1080 |
| 认证 | 与设备配对码关联 |
| 日志 | 启用访问日志 |

### 8.3.2 功能

- TCP 流量转发
- 连接管理
- 流量统计

## 8.4 REST API

### 8.4.1 接口列表

| 接口 | 方法 | 描述 |
|-----|------|------|
| /api/pair | POST | 创建配对会话 |
| /api/pair/{code} | GET | 验证配对码 |
| /api/device/{id}/status | GET | 获取设备状态 |
| /api/session/{id} | GET | 获取会话信息 |

### 8.4.2 认证

- API Key 认证
- JWT Token
