### 流量说明

| 流量类型 | 路径 | 说明 |
|---------|------|------|
| 控制指令 | 蜂窝 → MQTT | 云服务器通信，永不断线 |
| 内网访问（v1） | 工程师 → 云 SOCKS5(1080) → 反向隧道 → 手机 → WiFi | 不依赖工程师直连手机端口 |
| 公网访问（v2） | 手机应用 → VPN/TUN → 分流 → 蜂窝/云中转 | 仅在 VPN 接管模式启用 |
| DNS 查询（v2） | 本地 DNS 代理按策略选择 | 防泄漏优先：不并行双发 |

## 2.3 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                      移动端 (Android)                        │
├─────────────────────────────────────────────────────────────┤
│  UI层     │  Jetpack Compose + Material Design 3           │
├─────────────────────────────────────────────────────────────┤
│  业务层   │  Hilt 依赖注入 / Kotlin Coroutines + Flow      │
├─────────────────────────────────────────────────────────────┤
│  网络层   │  OkHttp │ MQTT (Eclipse Paho) │ VpnService     │
├─────────────────────────────────────────────────────────────┤
│  代理层   │  Netty (SOCKS5)                               │
├─────────────────────────────────────────────────────────────┤
│  系统层   │  Android 8.0+ (API 26)                        │
└─────────────────────────────────────────────────────────────┘
```
