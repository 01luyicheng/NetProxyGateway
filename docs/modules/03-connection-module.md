# 连接管理模块规格

## 3.1 模块概述

连接管理模块负责管理移动端的网络连接，实现双通道（WiFi + 蜂窝网络）同时在线，确保在任一网络故障时仍能保持连接。

## 3.2 双网卡检测

### 3.2.1 网络状态检测

- **API**: ConnectivityManager API
- **功能**: 实时检测 WiFi 和蜂窝网络状态
- **实现要点**:
  - 使用 `NetworkCallback` 监听网络切换事件
  - 检测网络可用性（isConnected）
  - 检测网络类型（wifi/mobile）

### 3.2.2 网络质量检测（可选优化）

- 检测网络延迟
- 检测丢包率
- 作为切换策略的参考

## 3.3 控制通道

### 3.3.1 MQTT 连接

> ⚠️ **配置说明**: 代码中可通过 `MqttConnectionManager.USE_TLS` 开关控制是否启用 TLS。
> - 生产环境: `USE_TLS = true` (端口 8883, TLS 加密)
> - 开发环境: `USE_TLS = false` (端口 1883, 普通 TCP)

| 配置项 | 生产环境 | 开发环境 |
|-------|---------|---------|
| 协议 | MQTT over TLS | MQTT over TCP |
| 端口 | 8883 | 1883 |
| 心跳间隔 | 30秒 | 30秒 |
| 重连策略 | 指数退避 (5s→60s) | 指数退避 (5s→60s) |

### 3.3.2 连接状态管理

```
┌─────────────┐     连接成功      ┌─────────────┐
│  初始状态   │ ──────────────► │  已连接     │
└─────────────┘                  └─────────────┘
       ▲                               │
       │          连接断开             │
       └───────────────────────────────┘
              (自动重连中)
```

## 3.4 分流规则引擎

### 3.4.1 内置路由表

- 云服务器 IP 段 → 蜂窝网络
- 内网 IP 段 → WiFi 网络

### 3.4.2 动态规则更新

- 通过 MQTT 下发分流规则
- 规则格式：IP段 → 网络接口

### 3.4.3 硬件分流（Android 13+）

- 使用 `excludeRoute` API 实现硬件级分流
- 减轻软件分流带来的性能开销
