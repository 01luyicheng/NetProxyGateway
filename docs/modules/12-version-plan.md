# 版本规划文档

## 12.1 版本路线图

### 12.1.1 v1.0.0 (MVP) - 核心功能

**目标**: 完成基本功能，支持远程协助核心场景

| 功能 | 描述 |
|-----|------|
| 双通道连接 | 蜂窝 + WiFi 同时在线 |
| 云端 SOCKS5 入口 + 反向隧道 | 工程师经云端访问设备侧 WiFi 内网 |
| 基础访问控制 | RFC1918 + 端口白名单 + 会话绑定 |
| 识别码配对 | 6 位数字配对码 |
| 基础 WiFi 控制 | WiFi 扫描和连接 |

**交付物**:
- Android 应用 v1.0.0
- 云服务端基础版
- MVP 文档

### 12.1.2 v1.1.0 - 完善与优化

**目标**: 提升稳定性和用户体验

| 功能 | 描述 |
|-----|------|
| 完善错误处理 | 各种异常场景处理 |
| 性能优化 | 提升转发效率 |
| 流量统计 | 流量使用统计 |
| 日志系统 | 完善日志记录 |

**交付物**:
- Android 应用 v1.1.0
- 服务端 v1.1.0

### 12.1.3 v2.0.0 - 扩展功能

**目标**: 扩展平台支持，增加企业功能

| 功能 | 描述 |
|-----|------|
| VPN 全局接管 | VpnService + Tun2Socks/等价方案 |
| 流量分流规则引擎 | 规则快照、动态更新、防泄漏 DNS 策略 |
| 多平台支持 | iOS 基础版 |
| 企业功能 | 团队管理 |
| 高级分流规则 | 自定义规则 |

**交付物**:
- Android 应用 v2.0.0
- iOS 应用 v1.0.0
- 管理后台

## 12.2 发布周期

| 版本 | 预计周期 | 里程碑 |
|-----|---------|-------|
| v1.0.0 | 4-6 周 | Alpha 测试 |
| v1.1.0 | 2-4 周 | Beta 测试 |
| v2.0.0 | 8-12 周 | 正式发布 |
