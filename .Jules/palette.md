## 2024-10-02 - AnimatedContent Button Spinner
**Learning:** For Jetpack Compose buttons displaying loading spinners during async operations, wrap the content in `AnimatedContent` to provide smooth transitions between default and loading states instead of abrupt visual swaps.
**Action:** When wrapping a `Button`'s inner elements with `AnimatedContent` for transitions, explicitly wrap the elements in a Row to preserve side-by-side layouts, as inserting `AnimatedContent` removes the implicit `RowScope` provided by the `Button`. Also, use `LocalContentColor.current` for the `CircularProgressIndicator` instead of hardcoding colors to ensure correct visual contrast in the disabled state.
