## 2023-10-27 - [Add proper keyboard type to Pairing Code Input]
**Learning:** Found that the pairing code input in the Android app (built with Compose) lacks `keyboardOptions` specifying `KeyboardType.Number` and doesn't restrict input length/type, which forces users to manually switch to a numeric keyboard and allows invalid entries. Adding explicit `KeyboardOptions(keyboardType = KeyboardType.Number, imeAction = ImeAction.Done)` along with a placeholder and a filter for 6-digit inputs greatly improves UX and prevents invalid inputs.
**Action:** When creating text inputs meant for verification/pairing codes, always configure the correct `keyboardOptions` (especially `KeyboardType.Number`) and enforce expected length/types via `onValueChange` and UI hints (`placeholder`) for a frictionless and robust user experience.
