## 2024-05-24 - [Add clear button to pairing code input]
**Learning:** Adding a clear button to an input field significantly improves UX, especially on mobile devices where backspacing can be tedious. Screen readers also need a `contentDescription` on the clear button icon.
**Action:** Always consider adding a trailing clear icon for text inputs where the user might want to quickly discard their entry. Ensure localized accessibility labels are provided.
