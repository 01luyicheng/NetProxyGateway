## 2023-10-25 - Smooth Transitions in Compose
**Learning:** In Jetpack Compose, when using `Crossfade` or `AnimatedContent` for smooth transitions (like status icons swapping), avoid computing derived state outside the animation lambda. Always compute derived properties (like the target icon) *inside* the lambda using the passed `targetState` parameter to prevent immediate outer-scope state updates from breaking the fade-out animation. Furthermore, abrupt color changes can be avoided using `animateColorAsState`.
**Action:** Use `animateColorAsState` for color transitions (like indicators or text tints). When swapping icons or text based on state, use `Crossfade(targetState = state) { currentState -> ... }` and ensure all references to the state inside the block use `currentState`.
